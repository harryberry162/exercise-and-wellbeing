# MOVE — The Science of Exercise & Wellbeing

A responsive, one-page research presentation website for a Welsh Baccalaureate project.

## Files
- `index.html` — page content and structure
- `style.css` — responsive sports-science visual design
- `script.js` — scroll animations, progress bar, mobile navigation and interactive barriers

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the externally hosted Unsplash photographs.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a **Public** repository named `exercise-and-wellbeing`.
2. Add the three website files (`index.html`, `style.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait a few minutes. GitHub Pages will show the published URL in the Pages settings.

## Important academic checks before submitting
- Replace the BBC, PubMed Central and Oxford placeholders with the exact article/study titles, authors and URLs from the sources you actually used.
- Check the wording and date of each source against the original publication. The Oxford description is based on the summary in the supplied research review and needs verification.
- Check whether the WHO factsheet you used is the 2024 edition; the link points to the WHO's current physical activity factsheet and may be updated over time.
- The 150–300 minute recommendation shown is for adults. Your presentation should explain that WHO recommendations differ by age group and individual circumstances.
- The website is a visual summary. Keep your full research review and complete reference list as supporting evidence if your teacher asks for them.

## Customising
Edit the text in `index.html`. Change colours and layout in `style.css`. Add or change interactions in `script.js`.
